# LLMBench

**Reproducible evaluation, benchmarking and regression testing for non-deterministic LLM and RAG systems.**

LLMBench runs every (model, prompt, sample) combination several times and scores quality,
consistency, failure rate, latency and cost. Every comparison then comes with confidence
intervals, a named statistical test and an effect size, plus a CI gate that fails only on
regressions you can trust.

- **[Live demo report](demo/report.html)** — a full HTML report regenerated by CI on every push

## Quickstart (no API keys, no cost)

```bash
git clone https://github.com/PiyushDas-2004/LLM-Bench.git && cd LLM-Bench
python -m venv .venv && source .venv/bin/activate && pip install -e .
llmbench run examples/quickstart.yaml
llmbench report latest
```
