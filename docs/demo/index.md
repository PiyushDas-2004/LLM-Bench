# Live demo

Everything on this page is **regenerated by GitHub Actions on every push to `main`** by
running LLMBench against its deterministic **mock provider**. No model API is called and
nothing is billed; the numbers are illustrative and exist to show the reports, not to
rank real models.

| Output | Command run in CI |
|---|---|
| [HTML report](report.html) | `llmbench run examples/quickstart.yaml` then `llmbench report latest` |
| [Leaderboard (Markdown)](quickstart.md) | `llmbench report latest --format md` |
| [Statistical comparison](comparison.md) | `llmbench compare <run> <run> --pair mock-fast/v2=mock-strong/v2 --format md` |
| [Eval gate on a seeded regression](gate.md) | `llmbench check --baseline main --gates examples/gates.yaml` |
| [Prompt-injection safety suite](safety.md) | `llmbench run examples/safety.yaml` |
| [RAG configuration sweep](rag_sweep.md) | `llmbench rag sweep examples/rag_sweep.yaml` |
| [Judge calibration vs human labels](calibration.md) | `llmbench judge calibrate datasets/judge_calibration.jsonl` |
